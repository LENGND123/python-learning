Understanding Python Syntax and Basics
Python Syntax Rules
1. Indentation:
Python uses indentation (spaces or tabs) to define blocks of code.
Example:
if 5 > 2:
    print("Five is greater than two!")

Note: Spaces before print() are called indentation.

2. Whitespace:
Python is sensitive to whitespace.
Ensure consistent indentation to avoid errors.
Ideally, use 4 spaces for indentation.
3. Statements:
Each line of code is a statement.
You can write multiple statements on one line using a semicolon (;), but this is not recommended.
Example:
print("Hello"); print("Python")

It is better to write:

print("Hello")
print("Python")
4. Comments:
Use # for single-line comments.
Example:
# This is a single-line comment
print("Hello Python")
Use ''' or """ for multi-line comments.
Example:
'''
This is a
multi-line comment
'''

Another example:

"""
This is a
multi-line comment
"""
